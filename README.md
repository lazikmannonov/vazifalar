# Kunlik vazifalar

HTML, CSS va JavaScript bilan yozilgan oddiy vazifalar ro'yxati.
Vazifalar brauzerning `localStorage` xotirasida saqlanadi, shuning uchun sahifani yopib ochsangiz ham yo'qolmaydi.

## Imkoniyatlar

- vazifa qo'shish va o'chirish
- bajarilgan deb belgilash
- bajarilganlarni birdan tozalash
- yorug va qorong'i rejim (qurilma sozlamasiga qarab)

## Ishga tushirish

`index.html` faylini brauzerda oching. Boshqa hech narsa o'rnatish shart emas.
